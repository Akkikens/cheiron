What an API client received for this request

{
  "error": {
    "code": "invalid_request",
    "message": "__MESSAGE__",
    "request_id": "__REQUEST_ID__"
  }
}

That is the same envelope every failure uses, carrying the same request_id as the response header. A 404 gets one for the same reason a timeout does: an error you cannot quote back is an error nobody can help you with.
